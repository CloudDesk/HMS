## Dental anatomy mesh attribution

The tooth meshes in this directory are derived from **BodyParts3D / Anatomography 4.3**.

- Data: © Database Center for Life Science (DBCLS)
- License: [CC BY-SA 2.1 Japan](https://creativecommons.org/licenses/by-sa/2.1/jp/deed.en)
- Source: https://lifesciencedb.jp/bp3d/
- Distribution mirror used for retrieval: https://github.com/olivercase/body_parts_3d_api

The application normalizes the source coordinates and assigns interactive clinical
surface regions at runtime. Those transformations are adaptations under the same
CC BY-SA 2.1 Japan license.

Included representative meshes cover upper and lower central/lateral incisors,
canines, first/second premolars, and first/second molars. Position 8 uses the
second-molar representative because the source collection does not include a
third-molar mesh. Primary incisors/canines use the matching tooth category;
primary positions 4 and 5 use first/second molar representatives. These are
interactive anatomical category models, not patient-specific scans.
